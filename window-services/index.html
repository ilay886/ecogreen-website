Signs You Need New Windows

  • Drafts near closed windows
  • Fog or moisture between the panes
  • Windows that stick or won’t stay open
  • Rotted or soft frames and sills
  • Rooms that feel hot in summer, cold in winter
  • Street noise coming through
  • Hard-to-clean windows that don’t tilt in
  • Rising energy bills

Window Questions, Answered

How long does window replacement take?

Most windows can be replaced in a day, and a whole house usually takes one to a few days, depending on how many windows you have and the trim work involved.

What is the difference between insert and full-frame replacement?

An insert window fits inside your existing frame, which is faster and keeps your trim. Full-frame replacement removes everything down to the opening, which is best when the old frames are rotted.

Will new windows lower my energy bills?

Energy-efficient glass and a tight seal usually make rooms more comfortable and can lower heating and cooling costs, especially if you are replacing old single-pane or drafty windows.

Do you work on older homes?

Yes. On homes built before 1978 we follow EPA lead-safe practices, and we can match the look of older windows with the right style and trim.

How do I know which window style is right for each room?

It depends on how you use the room. Casements seal tight and catch side breezes, double-hung windows are easy to clean, sliders suit wide openings, and picture windows give the best view. We walk through each room with you and suggest what fits.

Can you replace just a few windows instead of the whole house?

Yes. Many homeowners start with the worst windows and do the rest later. We’ll match the style and color so new windows look right next to the existing ones.
